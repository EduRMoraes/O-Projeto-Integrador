# 🎙️ Roteiros de Fala e Divisão de Apresentação

Esta pasta reúne o planejamento verbal, os scripts de fala (*speechs*) e a organização dos tempos de apresentação da equipe para a defesa do **Projeto Integrador da Biblioteca Virtual TG Americana** perante a banca examinadora da UNISAL.

---

## 📌 Objetivo dos Roteiros

O roteiro tem como finalidade garantir uma **apresentação fluida, articulada e sincronizada** entre os integrantes, evitando atropelos de fala, esquecimento de pontos técnicos críticos e estouro do tempo limite estipulado pela banca.

---

## 📋 Boas Práticas para o Roteiro

- **Sincronia com os Slides**: O script de fala deve estar diretamente alinhado às transições dos slides para que a mudança de tela sirva como gatilho de memória.
- **Linguagem Técnica**: Utilizar terminologia adequada da Engenharia de Software e IHC (ex: *"operação 100% offline"*, *"persistência de dados"*, *"regras de negócio"*, *"usabilidade"*).
- **Ensaio e Cronometragem**: Realizar simulações gravadas ou em grupo para alinhar a postura visual e o ritmo das falas.
